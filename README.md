# Product Calculation Table

This project is a simple Product Calculation Table built using HTML and CSS. It displays product details such as product name, quantity, unit price, and total amount in a structured table format.


## Features

* Well-structured product table
* Product quantity and price calculations
* Total amount calculation
* Hover effect on table rows
* Styled table headers
* Clean and easy-to-read layout

## Technologies Used

* HTML
* CSS


## Table Contents

The table contains:

* Serial Number
* Product Name
* Quantity
* Per Unit Price
* Amount
* Grand Total

It includes multiple sample products and calculates a final total amount.

## How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in any web browser.
